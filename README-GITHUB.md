# MISI BAKUL NOMBOR — Pilihan 0–5 / 0–10 dan Bukit Tanpa Nombor

## Cara muat naik ke GitHub Pages
1. Ekstrak ZIP ini.
2. Buka repository GitHub yang menempatkan permainan.
3. Gantikan `index.html` lama di **root** repository dengan `index.html` ini.
4. Tunggu GitHub Pages deploy, kemudian muat semula laman.

## Perubahan khusus
- Misi 3: nombor 1, 2, 3 di dalam bukit/tangga dibuang untuk susunan menaik dan menurun. Bukit dan anak panah kekal.
- Butang tetapan ⚙️ kini membuka menu yang membolehkan murid memilih **0–5** atau **0–10**.
- Nombor sifar benar-benar boleh muncul dalam tiga misi: Misi 1 memaparkan `Tiada buah · 0`, Misi 2 membenarkan bakul kosong dihantar, Misi 3 memaparkan bakul 0 sebagai `Kosong`.
- Mod webcam berbentuk bintang, latar webcam, jejak bintang, MediaPipe, watak dan reka bentuk lain dikekalkan.

**Nota:** Webcam memerlukan HTTPS dan kebenaran kamera dalam browser. Kod MediaPipe mengambil model melalui rangkaian.
